# 🏋️ AI-Powered Fitness Coach & Biomechanical Form Analyzer

A real-time Computer Vision and Deep Learning fitness form correction engine built for 3rd-year university academic AIML project evaluation and viva defense.

The system connects a **React/TypeScript dynamic frontend**, **FastAPI high-performance backend**, **MediaPipe 3D pose extraction**, **142 engineered biomechanical features**, **multi-model inference** (Random Forest, XGBoost, and PyTorch Bi-LSTM), and **deterministic state-machine repetition counting**.

---

## 🌟 Key Features

- **3D Kinematic Pose Tracking:** MediaPipe 33-landmark estimation with hip-centered, scale-invariant normalization.
- **Biomechanical Angle Engine:** 3D vector calculations for elbows, knees, hips, shoulders, spine inclination, and bilateral asymmetry.
- **Multi-Model Machine Learning (measured on video-level holdout splits — see `reports/model_evaluation/`):**
  - **Random Forest:** Exercise recognition across Squat, Push-up, Bicep Curl, and Shoulder Press (measured test accuracy 95.2%, macro F1 0.952 on the holdout test set).
  - **XGBoost:** Form fault detection trained on biomechanical weak labels (rule-generated, NOT human-annotated — see Limitations). Measured validation accuracy 81.0%, macro F1 0.696; sub-millisecond inference (~0.4ms).
  - **PyTorch Bi-LSTM (30-frame windows):** Temporal sequence modeling (measured validation accuracy 83.9%, val F1 0.850, best checkpoint `bilstm_best.pth`; training accuracy saturates ~100% so treat val metrics as the honest figure).
- **Hysteresis State-Machine Rep Counter:** Multi-phase tracking (`IDLE` → `ECCENTRIC` → `INFLECTION` → `CONCENTRIC` → counted) with person-adaptive completion (return-to-start reference + absolute lockout thresholds), re-descent/re-ascent recovery, minimum-duration gating, and end-of-stream flush so the final rep is not lost.
- **Server-Sent Events (SSE):** Real-time frame-by-frame progress streaming with live joint angle gauges and instant coaching cues.
- **Publication-Quality PDF Reports:** Automated generation of medical/sports-grade workout evaluations with SVG radar charts and rep-by-rep telemetry tables.

## 🏗️ Architecture Pipeline

```
Video Stream / File (OpenCV)
            ↓
MediaPipe Pose (33 3D Keypoints)
            ↓
Biomechanical Feature Engineering (142 Features: Angles, Distances, ROM, Jerk)
            ↓
Exercise Classifier (Random Forest / PyTorch Bi-LSTM)
            ↓
State-Machine Repetition Counter (Inflection Detection)
            ↓
Form Fault Classifier (XGBoost + Biomechanical Rule Engine)
            ↓
Multi-Dimensional Scoring Engine (Accuracy, ROM, Tempo, Symmetry)
            ↓
Coaching Feedback & Actionable Corrective Drills
            ↓
Supabase Database & SSE Real-Time React Dashboard
```

## 🚀 Quick Start Guide

### 1. Prerequisites
- Python 3.10+ (tested on Python 3.12)
- Node.js 18+ and npm
- (Optional) Docker & Docker Compose

### 2. Backend Setup
```bash
# Install Python requirements
pip install -r requirements.txt

# Start FastAPI backend (port 8000)
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```
API Documentation will be available at `http://localhost:8000/docs`.

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Running with Docker Compose
```bash
docker-compose up --build
```

- **Hammer Curl Exclusion:** Excluded 19 non-target videos.
- **External Test Isolation:** `my_test_video_1` quarantined strictly as holdout test set.

## ⚠️ Limitations (read before the viva)
- **Form labels are weak labels**, generated by documented biomechanical rules (`backend/app/ml/features/form_labels.py`), NOT human-annotated ground truth. XGBoost therefore learns to approximate the rule engine, not independent human judgment.
- **Bicep-curl recall is the weakest class** (RF val recall ~0.42); curls are most often confused at frame level — majority voting across frames mitigates this in full-video inference.
- **LSTM overfits the training windows** (train acc ~100% vs val F1 0.85); the shipped checkpoint is the best-validation epoch, not the final epoch.
- **Auth is demo-grade** (no password hashing; unauthenticated requests fall back to a demo user). Supabase Auth integration is the recommended next step before any production use.
- **Smoothness scores are relative**, derived from jerk on the smoothed primary joint — useful for within-user trends, not absolute norms.

python backend/app/ml/xgboost_model/train.py
python backend/app/ml/lstm/train.py
